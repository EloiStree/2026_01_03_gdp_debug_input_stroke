In-app key logger for actions
Allows actions to be triggered based on key events within the application.

This is not an operating system key logger.
The purpose is to listen for and abstract key events in the application so they can be used to trigger specific actions. Human beings insist on overloading the phrase "key logger" with decades of security baggage, so it's worth making this distinction explicit.
