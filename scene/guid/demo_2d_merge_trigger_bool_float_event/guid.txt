Merger Trigger / Bool / Float
Merges key events in a singleton for trigger, bool, and float values.

This provides an abstraction layer between the complexity of the input system and external applications that only require key-based trigger, boolean, or float values.     
The system could be extended to support types such as Vector3, Quaternion, or int, but the goal is to remain close to the original HID model by focusing on boolean and analog inputs. Humanity does enjoy inventing infinite data types when two are often enough.
